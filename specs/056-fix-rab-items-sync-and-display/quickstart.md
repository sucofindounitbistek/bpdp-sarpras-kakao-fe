# Quickstart & Verification Guide: Fix RAB Items Synchronization and Display

## Verification Steps

1. Start dev server:
   ```bash
   cd bpdp-sarpras-kelapa-fe
   npm run dev
   ```
2. Open proposal verification page: `/dinas/verifikasi/kabupaten/:id`.
3. Verify RAB table displays all RAB items with budget stage columns, volume, unit price, and total.
4. Run build verification:
   ```bash
   npm run build
   ```
