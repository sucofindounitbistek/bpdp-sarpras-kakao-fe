# Quickstart Guide: Provincial Dinas Institutional Accounts (034-sidebar-lembaga-provinsi)

## Manual Validation Steps

1. Start development server: `npm run dev`
2. Open browser at `http://localhost:5173`
3. Switch role to **Dinas Provinsi** (`DINAS_PROV`).
4. Inspect the sidebar under section **DINAS PROVINSI**.
5. Verify the new **"Lembaga"** menu item with `Building2` icon is visible.
6. Click "Lembaga".
7. Verify URL navigates to `/dinas/provinsi/lembaga` and displays **Daftar Akun Kelembagaan Pekebun**.
8. Test searching by organization name and filtering by district.
9. Click "Detail" on an organization row to view complete institutional account profile modal.
