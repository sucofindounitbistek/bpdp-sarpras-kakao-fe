# Quickstart & Verification Guide: Fix Proposal Detail Documents Mapping

## Verification Steps

1. Start dev server:
   ```bash
   cd bpdp-sarpras-kelapa-fe
   npm run dev
   ```
2. Open proposal verification page: `/dinas/verifikasi/kabupaten/:id`.
3. Verify that all proposal documents (Surat Permohonan, Legalitas Kelembagaan, Proposal Teknis, RAB) appear with title, file size, and view action.
4. Run build verification:
   ```bash
   npm run build
   ```
