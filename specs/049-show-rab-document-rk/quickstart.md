# Quickstart & Verification Guide: Show RAB Document using RAB_RK

## Prerequisites
- Node.js environment
- Frontend server running
- Logged in as **Dinas Kabupaten** role

## Verification Procedure

### Scenario 1: Step 1 RAB Document Verification
1. Open proposal verification page.
2. Ensure proposal has a document of type `RAB_RK` uploaded.
3. Under **Pemeriksaan RAB**, verify:
   - File name matches the `RAB_RK` file.
   - File size matches the `RAB_RK` size.
4. Click **Lihat**. Verify that preview modal successfully renders the file.

### Scenario 2: Step 4 Summary Verification
1. Proceed to Step 4.
2. Under **Step 1 Summary** -> **RAB**, verify:
   - The document displayed matches the `RAB_RK` document.
   - Clicking **Pratinjau** opens the correct file preview modal.
